# Diş Kliniği Otomasyonu

C# Windows Forms ile geliştirilmiş diş kliniği otomasyon sistemi.

## Özellikler
- Hasta kaydı ekleme, düzenleme, silme
- Tedavi takibi
- Randevu yönetimi
- Reçete işlemleri

## Kullanılan Teknolojiler
- C# / Windows Forms (.NET Framework)
- SQL Server LocalDB
- Visual Studio

## Kurulum
1. Repoyu indir (Code → Download ZIP).
2. SQL Server LocalDB'de DentalDb adında bir veritabanı oluştur.
3. veritabanı.sql dosyasını bu veritabanında çalıştır.
4. .slnx dosyasını Visual Studio ile aç ve çalıştır.
